# Upstream provenance

SteamOS Waydroid Bundle is an independently maintained, modified continuation
of Ryan Rudolf's SteamOS Waydroid Installer. It is not an official release of,
affiliated with, or endorsed by the original project or its maintainers.

## Source snapshot

- Original repository: `ryanrudolfoba/SteamOS-Waydroid-Installer`
- Historical URL: <https://github.com/ryanrudolfoba/SteamOS-Waydroid-Installer>
- Incorporated branch: `testing`
- Incorporated commit: `d08a1dc35fc9f8a17ca6cdf96f043d486e73598c`
- Commit date: 2026-07-16
- Commit author: Ryan Rudolf (`ryanrudolfoba`)

The original repository was publicly available with a GNU GPL version 3
licence when this source was obtained. As of 2026-08-04, it is not accessible
to unauthenticated GitHub users. The complete incorporated history remains in
this repository so authorship, dates, and the development lineage can be
inspected without relying on the historical URL.

## Independent modifications

Independent modifications began on 2026-07-17. They include reproducible
target-specific SteamOS build environments, verified binary bundles, exact
userspace compatibility fingerprints, public artifact selection, safer repair
and reset behaviour, and separation of installer runtime helpers from
maintainer tooling. The Git history records each modification and its author.

## Future upstream availability

The historical Git remote is not required to build, install, or maintain this
project. If the original repository becomes publicly available again, it may
be used for comparison, but changes will be reviewed and deliberately ported
rather than merged automatically.
